# Facebook Reels, ready to paste

Nine cuts, one per run. Nothing here has been posted or scheduled.

## How to use this

**Upload the `-silent.mp4`.** It has no audio stream at all, by design. Pair it
with a track from Facebook's own in-app music library at upload. Audio picked
there is licensed for the platform and is favoured by its distribution, whereas a
self-supplied track that is not cleared gets muted or region blocked.

**The `-scored.mp4` in the same folder is not the feed upload.** It carries a
BrandGEO-composed track and exists for paid placements, site embeds and decks,
where the in-app library does not exist.

**Paste the body as written.** Facebook renders the link in the post body
directly, so the URL sits on its own line at the end and needs no first-comment
trick. Line breaks are intentional. Every body runs 80 to 150 words, which is
longer and plainer than the TikTok copy for the same cut, because this audience
reads more and tolerates less category vocabulary.

**Each body extends the video rather than restating it.** The video makes the
argument; the caption carries what the video had no room for, which is usually
the mechanism, the source, or the limit on the claim. If you shorten one, cut
from the middle, not the end, because the last line before the link is the only
thing doing CTA work.

**No figure in any of these copy blocks is illustrative.** Where a number
appears it was measured by BrandGEO's own collection pipeline and the page it
was measured on is linked in the same block.

## 4. Contrarian

**Silent master:** `docs/growth/reel-campaign-ab/run-20260730-0113/facebook/facebook-silent.mp4`
**Hook driver:** #4, contrarian
**What it argues:** a page one Google ranking and being named in an AI answer are
two separate measurements, and one does not predict the other.

```
What makes that audit worth reading is not the gap itself. It is that the
business had no way to notice it. Their rankings were fine, so their reporting
said everything was fine.

A rank tracker measures a position in a list of links. It has no view of whether
a company gets named inside a generated answer, because that answer is a
different artefact built by a different system from different signals.

So the two have to be watched separately. Neither replaces the other, and a good
result in one is not evidence about the other. That is the whole argument, and it
is smaller and more boring than "search is finished", which is why it holds up.

The full audit is published, including the exact questions we put to each engine:

https://getbrandgeo.com/bg-004.html
```

```
Madrid was a coverage problem. Paris, tested the same day, was something else.
```
