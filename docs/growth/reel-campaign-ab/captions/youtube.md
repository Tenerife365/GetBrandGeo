Nine cuts, one per run. Nothing here has been posted or scheduled.

## How to use this

**Upload the `-silent.mp4`.** It has no audio stream at all, by design. Pick a
track from YouTube's own audio library at upload. Audio picked there is licensed
for the platform and is favoured by its distribution, whereas a self-supplied
track that is not cleared gets muted or region blocked.

**The `-scored.mp4` in the same folder is not the feed upload.** It carries a
BrandGEO-composed track and exists for paid placements, site embeds and decks,
where the in-app library does not exist.

**The title is what gets shown, so it carries the argument in one clause.** No
keyword stuffing, no colon-and-brackets construction, no bracketed year, no all
caps. Paste it as written.

**The description is written to be read by a person who paused on the video**,
not to be crawled. It extends the on-screen argument rather than restating it,
and it carries the source links so the figures are checkable, which is the whole
point of using real ones. The primary link sits after the argument; research
links go last.

**Tags go in the tag field, not in the description.** Three to five per cut,
listed under each block. No trailing hashtag run inside the copy, because it
does not serve the reader the description is written for.

**No figure in any description is illustrative.** Where a number appears it was
measured by BrandGEO's own collection pipeline, and the page it was measured on
is linked in the same block.

4. **Cut 2 description, replaced.** Same verbatim-reuse problem: `Ask again

5. **Cut 3 title, kept verbatim.** It states the setup and withholds the finding,

6. **Cut 3 description, rewritten.** Its sourcing and its figures were right and
