Link each suggestion to the matching live comparison page already on

`docs/DIRECTORY-LISTINGS-KIT.md`'s prior note on this exact practice.

flags a listed alternative as "genuine" only if the comparison is honest;
overclaiming here risks the listing being marked non-genuine or removed.
