# BG-107 data record: answers that named no firm at all

Re-run 2026-10-31 against production (`duiyifepitvugyulobqm`), read-only.
No person's name is recorded here: the repository is public.

## Basis

- Clients 28 to 47: the 20 US city research accounts, collected 2026-07-24 and 2026-07-25.
- Prompt type is the prompt's order inside its client: 1 personal injury lawyer,
  2 real estate agents, 3 property management, 4 immigration lawyer, 5 and 6 city-specific.
- Five engines, `status = 'ok'` only: 591 answers (chatgpt 120, claude 120, gemini 120,
  google_ai 111, perplexity 120).
- Text read: `response_text`. `citations` is null on every row and was not used.

## Method, and why it is a hand count

The topic brief started from rows where `competitors_mentioned` is empty. That field is
not reliable (capped at 10, misses bullet lists; see topic 2's drop note), so it was used
only to pick which rows to read. 162 rows are empty there: chatgpt 12, claude 10,
gemini 28, google_ai 72, perplexity 40.

Every one of the 162 was checked against its text:

- chatgpt 12, claude 10: every answer names firms or professionals in bold. 0 no-firm.
- gemini 28: every answer names at least one firm. The three thinnest (a Los Angeles
  personal injury answer, a Phoenix agent answer, a San Francisco immigration answer)
  were read in full: each names firms or brokerages in a closing section. 0 no-firm.
- google_ai 72: every answer names businesses in its opening sentence or headings,
  including the four with no firm-type word (custom home builders, retirement communities,
  home services, coffee). 0 no-firm.
- perplexity 40, all read in full: 15 name no firm, brokerage or individual professional
  at all. 22 name individuals (parser misses). 3 name exactly one or two firms while
  saying the results were too limited (a Minneapolis medical device question, a Detroit
  automotive question flagged by the engine itself as a weak match, and a Phoenix home
  services question); these count as answers that named a firm.

A row that names only a directory, a ranking publication or a government office counts
as no-firm. Four of the 15 are like that (a Best Law Firms ranking, a Washingtonian list,
general agent directories, a buyer's-agent checklist with no names).

## The 15 hand-confirmed ids

2431, 2556, 2566, 2626, 2661, 2731, 2756, 2786, 2821, 2906 (real estate agents);
2481, 2581 (immigration); 2546 (personal injury); 2651, 2886 (city-specific).

## Query that reproduces every published number

```sql
with p as (
  select id, client_id, row_number() over (partition by client_id order by id) rn
  from prompts where client_id between 28 and 47
), r as (
  select a.id, a.llm, a.client_id,
    case p.rn when 1 then 'personal_injury' when 2 then 'real_estate'
              when 3 then 'property_mgmt' when 4 then 'immigration'
              else 'city_specific' end qtype,
    length(a.response_text) len,
    a.id in (2431,2556,2566,2626,2661,2731,2756,2786,2821,2906,
             2481,2581,2546,2651,2886) nofirm,
    (a.response_text ~* '(don.t|do not) have (any )?(search results|results|access)|search results (you provided |provided )?(are|is) (too limited|insufficient)|results are \*{0,2}insufficient|not enough (information|results) to|can.t verify|cannot verify|unable to verify|without (search )?results') refusal
  from ai_results a join p on p.id = a.prompt_id
  where a.client_id between 28 and 47 and a.status = 'ok'
)
select 'engine' k, llm g, count(*) n, count(*) filter (where nofirm) nofirm,
  count(*) filter (where refusal) refusal, round(avg(len)) avglen,
  round(avg(len) filter (where nofirm)) nofirm_len
from r group by llm
union all
select 'pplx_qtype', qtype, count(*), count(*) filter (where nofirm),
  count(*) filter (where refusal), round(avg(len)), round(avg(len) filter (where nofirm))
from r where llm = 'perplexity' group by qtype
union all
select 'pplx_cities_nofirm', null, count(distinct client_id), null, null, null, null
from r where nofirm
order by 1, 2;
```

## Claims checked before publishing

- "Perplexity declines more than other engines" is stated only as counts in this
  dataset (15 versus 0). No claim about why, and no claim about other dates.
- The refusal regex alone undercounts (it finds 9 of the 15) and overcounts (3 matches
  named a firm), so the article uses the hand list, not the regex, for the headline.
- In the 10 cities where Perplexity named no agent, the other engines gave 38 usable
  agent answers (Google AI Mode has none for clients 39 and 42), and every one names
  agents or brokerages (0 no-firm rows outside Perplexity).
- Looser reading for the article's "near misses" section: 15 no-firm plus the 3
  refusal-worded answers that named one or two firms (ids 2826, 2856, 2621) = 18 of 120.
- Perplexity property management answers average 1,947 characters, its longest type.
