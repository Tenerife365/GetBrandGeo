# BG-108 data record: star ratings and review counts quoted in answers

Re-run 2026-11-01 against production (`duiyifepitvugyulobqm`), read-only (SELECT and WITH only).
No person's name is recorded here: the repository is public.

## Basis

- Clients 28 to 47: the 20 US city research accounts, collected 2026-07-24 and 2026-07-25.
- Prompt type is the prompt's order inside its client (`row_number() over (partition by
  client_id order by id)` on `prompts`): 1 personal injury lawyer, 2 real estate agents,
  3 property management, 4 immigration lawyer, 5 and 6 city-specific.
- Five engines, `status = 'ok'` only: 591 answers (chatgpt 120, claude 120, gemini 120,
  google_ai 111, perplexity 120). Per type: pi 98, re 98, pm 99, imm 98, city 198.
- Text read: `response_text`. `citations` is null on every row and was not used.
- Excluded: `ai_results.id = 2892` (google_ai, Tampa, city-specific). Its only match is a
  hotel class filter ("5.0 Star. 3.5 Star.") inside a link title. False positive.

## Method

The topic brief's two patterns missed common forms ("**5.0** rating on Avvo",
"4.9 Google rating") and the old review pattern matched the literal `& Reviews` text in
Google AI Mode link titles (ids 2412 and 2702). Final patterns, Postgres, case-insensitive:

```
rating   = t ~* '\m[1-5](\.\d)?\s*(-\s*)?(stars?|★|⭐)'
        or t ~* '\m[1-5](\.\d)?\s*/\s*5\M'
        or t ~* '\m[1-5](\.\d)?\s*out of 5\M'
        or t ~* '\m[1-5]\.\d\s*\**\s*(google |zillow |yelp |avvo |bbb |star )?(ratings?|rated|average)'
        or t ~* '(rating|rated)( of)?\s*\**\s*[1-5]\.\d'
revcount = t ~* '\m\d[\d,.]*\s*k?\+?\s*\**\s*(google |online |client |customer |verified |five-star |5-star |zillow |yelp )?(reviews|reviewers)\M'
```

About 65 matched snippets were read by hand across engines and types; all were genuine
ratings or review counts apart from the false positives named above.

## Query

```sql
with p as (
  select id, client_id, row_number() over (partition by client_id order by id) rn
  from prompts where client_id between 28 and 47
), r as (
  select a.id, a.llm, a.client_id,
         case p.rn when 1 then 'pi' when 2 then 're' when 3 then 'pm' when 4 then 'imm' else 'city' end typ,
         a.response_text t
  from ai_results a join p on p.id = a.prompt_id
  where a.client_id between 28 and 47 and a.status = 'ok'
    and a.llm in ('chatgpt','claude','gemini','google_ai','perplexity')
), f as (
  select *,
    id <> 2892 and (t ~* '\m[1-5](\.\d)?\s*(-\s*)?(stars?|★|⭐)' or t ~* '\m[1-5](\.\d)?\s*/\s*5\M'
     or t ~* '\m[1-5](\.\d)?\s*out of 5\M'
     or t ~* '\m[1-5]\.\d\s*\**\s*(google |zillow |yelp |avvo |bbb |star )?(ratings?|rated|average)'
     or t ~* '(rating|rated)( of)?\s*\**\s*[1-5]\.\d') rating,
    id <> 2892 and (t ~* '\m\d[\d,.]*\s*k?\+?\s*\**\s*(google |online |client |customer |verified |five-star |5-star |zillow |yelp )?(reviews|reviewers)\M') revcount
  from r
)
select llm, typ, count(*) answers,
       count(*) filter (where rating) rating,
       count(*) filter (where revcount) revcount,
       count(*) filter (where rating or revcount) either
from f group by grouping sets ((), (llm), (typ), (llm, typ)) order by 1, 2;
```

Id 2892 stays in the 591-answer base and counts as an answer with no rating or review count.
