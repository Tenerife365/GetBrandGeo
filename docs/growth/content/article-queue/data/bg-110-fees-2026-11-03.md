# BG-110 data record: fees in AI answers (2026-11-03)

Topic 7 `fees` from `topics.md`. Read only; SELECT and WITH only. No person's
name, firm name, address or phone number is recorded here: the repository is
public.

## Basis

- Clients 28 to 47 (20 US city research clients), `ai_results.status = 'ok'`,
  engines chatgpt, claude, gemini, google_ai, perplexity: 591 answers
  (chatgpt 120, claude 120, gemini 120, google_ai 111, perplexity 120).
- Prompt type by `row_number() over (partition by client_id order by id)`:
  1 personal injury, 2 real estate, 3 property management, 4 immigration,
  5 and 6 city-specific.
- Answers per engine for types 1 to 4: 20 each, except google_ai
  (18 personal injury, 18 real estate, 19 property management, 18 immigration).
- Collection ran 2026-07-24 and 2026-07-25. Stored text stops near 2,500
  characters for Claude and 10,000 for Google AI Mode.

## Method (final patterns)

- Backslashes stripped from `response_text` first.
- Property management fee percentage:
  `\d{1,2}(\.\d+)?\s?%[^.\n]{0,30}(of (the )?(monthly |collected |gross )?rent)|management (fee|pric)[^.\n]{0,60}\d{1,2}(\.\d+)?\s?%|(charge|fees?|tier|pricing)[^.\n]{0,40}\d{1,2}(\.\d+)?\s?%`
  All 20 matching answers read by hand; each quotes a real management fee
  percentage (general range or a named company's rate). Ids 2598, 2635 and
  2775 also hold non-fee percentages (a URL `%20`, "100% of clients", a rent
  collection rate) but each also quotes a fee, so all three stay in.
- Other flags: `contingenc`; free consultation
  `free (initial )?(case )?(consult|evaluation|review)`; no win no fee
  `no (win|recovery),? no fee|no fee unless|(don.t|do not|never) pay (anything )?unless|only (get )?paid if|unless (we|they) win`;
  `(leasing|placement) fee`; `flat[ -]fee|flat[ -]rate`; `commission`.
- Buyer agent pay question (real estate):
  `(how (the |your )?(buyer.s )?agent (is|gets|will be) (paid|compensated)|buyer.agent (agreement|compensation)|commission (rules|practices|structure)s? (have )?changed|NAR settlement|compensation agreement)`
  15 ChatGPT matches read by hand, all genuine; 0 on the other engines.
- Personal injury percentages (3) and real estate percentages (2) read by
  hand. Two of the personal injury quotes are one firm's discounted rate set
  against a stated norm; those firms are not named.
- City-specific questions (198 answers): 0 fee percentages.
- No quoted fee was checked for accuracy.

## Query

```sql
with p as (
  select id, client_id, row_number() over (partition by client_id order by id) rn
  from prompts where client_id between 28 and 47
), r as (
  select a.id, a.llm, p.rn, replace(a.response_text, chr(92), '') t
  from ai_results a join p on p.id = a.prompt_id
  where a.client_id between 28 and 47 and a.status = 'ok'
    and a.llm in ('chatgpt','claude','gemini','google_ai','perplexity')
), f as (
  select *,
   t ~* '\d{1,2}(\.\d+)?\s?%[^.\n]{0,30}(of (the )?(monthly |collected |gross )?rent)|management (fee|pric)[^.\n]{0,60}\d{1,2}(\.\d+)?\s?%|(charge|fees?|tier|pricing)[^.\n]{0,40}\d{1,2}(\.\d+)?\s?%' pm_pct,
   t ~* '(leasing|placement) fee' leasefee,
   t ~* 'flat[ -]fee|flat[ -]rate' flat,
   t ~* 'contingenc' conting,
   t ~* 'free (initial )?(case )?(consult|evaluation|review)' freeconsult,
   t ~* 'no (win|recovery),? no fee|no fee unless|(don.t|do not|never) pay (anything )?unless|only (get )?paid if|unless (we|they) win' nowin,
   t ~* 'commission' commission
  from r
)
select coalesce(llm,'ALL') llm, rn, count(*) n,
 count(*) filter (where pm_pct) pm_pct, count(*) filter (where leasefee) leasefee,
 count(*) filter (where flat) flat, count(*) filter (where conting) conting,
 count(*) filter (where freeconsult) freeconsult, count(*) filter (where nowin) nowin,
 count(*) filter (where commission) commission
from f where rn <= 4 group by grouping sets ((rn),(llm,rn)) order by rn, 1;
```
