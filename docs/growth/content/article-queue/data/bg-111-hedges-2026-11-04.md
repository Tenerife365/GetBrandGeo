# BG-111 data record: buyer vetting advice in AI answers (2026-11-04)

Topic 8 `hedges` from `topics.md`. Read only; SELECT and WITH only. No person's
name, firm name, address or phone number is recorded here: the repository is
public.

## Basis

- Clients 28 to 47 (20 US city research clients), `ai_results.status = 'ok'`,
  engines chatgpt, claude, gemini, google_ai, perplexity: 591 answers
  (chatgpt 120, claude 120, gemini 120, google_ai 111, perplexity 120).
- Prompt type by `row_number() over (partition by client_id order by id)`:
  1 personal injury, 2 real estate, 3 property management, 4 immigration,
  5 and 6 city-specific.
- Collection ran 2026-07-24 and 2026-07-25. Stored text stops near 2,500
  characters for Claude.

## Method (final patterns)

Backslashes stripped from `response_text` first. Four families of advice
aimed at the buyer, each read by hand in samples and tightened:

- cred (license or bar record):
  `(verify|confirm|check|look up|cross-check)[^.\n]{0,70}(licen[cs]|bar (status|directory|website|membership|search)|state bar|disciplin|good standing|credential|DRE|TREC)`
- rev (reviews):
  `(verify|check|read|look at|cross-check)[^.\n]{0,40}(recent |online |google |client |owner |peer )?(reviews|references|testimonials)`
- sev (interview several): the pattern below, where `<EN>` is the en dash
  character, passed in the query as `chr(8211)` so this file holds none:
  `(interview|meet with|speak with|talk to|talk with|consult with|compare)[^.\n]{0,20}(two|three|several|multiple|a few|at least|more than one|[23](\s?(-|<EN>|to)\s?[345])?)\s+(agents|firms|lawyers|attorneys|candidates|companies|managers|professionals|of them|different|options|before)|interview (multiple|several|a few)|speak with a few`
- ask (questions to ask):
  `questions to ask|ask (them|each|the (agent|lawyer|attorney|firm|company|manager)|about|whether|if|how|what)\M`
- no results (Perplexity context, not advice):
  `I (don.t|do not) have (any )?(live |current |real-time )?search results|can.t (reliably|responsibly)`

Dropped while tightening: bare `verify` (caught "verified reviews" and
engines' own hedges), `call` and `contact` (caught phone numbers), bare
`compare` (caught fee percentages), `ask for` (caught review quotes),
`search` in the credentials family. Known remaining false positive class:
Google AI Mode page text quoting a firm's own site ("read our reviews").

## Query

```sql
with p as (
  select id, client_id, row_number() over (partition by client_id order by id) rn
  from prompts where client_id between 28 and 47
), r as (
  select a.id, a.llm, p.rn, replace(a.response_text, chr(92), '') t
  from ai_results a join p on p.id = a.prompt_id
  where a.client_id between 28 and 47 and a.status = 'ok'
), f as (
  select llm, rn,
   t ~* '<cred pattern>' a_cred,
   t ~* '<rev pattern>' a_rev,
   t ~* ('<sev pattern, with ' || chr(8211) || ' in the dash slot>') b_sev,
   t ~* '<ask pattern>' c_ask
  from r
)
select llm, count(*) n, sum(a_cred::int) cred, sum(a_rev::int) rev,
  sum(b_sev::int) sev, sum(c_ask::int) ask,
  sum((a_cred or a_rev or b_sev or c_ask)::int) any_adv,
  sum(((a_cred::int + a_rev::int + b_sev::int + c_ask::int) >= 3)::int) three_plus
from f group by rollup(llm) order by llm;
```
