# BG-109 data record: addresses, phone numbers and links in AI answers (2026-11-02)

Topic 6 `nap` from `topics.md`. Read only; SELECT and WITH only. No address,
phone number or person's name is recorded here: the repository is public.

## Basis

- Clients 28 to 47 (20 US city research clients), `ai_results.status = 'ok'`,
  engines chatgpt, claude, gemini, google_ai, perplexity: 591 answers
  (chatgpt 120, claude 120, gemini 120, google_ai 111, perplexity 120).
- Prompt type by `row_number() over (partition by client_id order by id)`:
  1 personal injury, 2 real estate, 3 property management, 4 immigration,
  5 and 6 city-specific.
- Collection ran 2026-07-24 and 2026-07-25. Stored text stops near 2,500
  characters for Claude and 10,000 for Google AI Mode.

## Method (final patterns)

- Backslashes stripped from `response_text` first (markdown escapes such as
  `\(` hid some phone numbers from the first pass).
- Phone: `(\(\d{3}\)|\m\d{3})[ .-]\d{3}[ .-]\d{4}\M`
- Street address (case-insensitive):
  `\m\d{2,6} [A-Za-z0-9 .]{2,40} (st|street|ave|avenue|blvd|boulevard|road|rd|drive|dr|suite|ste|pkwy|parkway|fwy|freeway|hwy|highway|way|lane|ln)\M`
- Excluded: id 2489 (Gemini; the match was a newspaper name, not an address).
- Link: `https?://` anywhere in the text.
- About 100 matches read by hand. Addresses were genuine street addresses of
  named firms, offices and hospitals. Google AI Mode answers carry the page
  text of cited sources, so part of its address count and much of its phone
  count sits in quoted snippet text (office pages, agent profiles, listing
  titles, a few fax lines); two answers contain placeholder text. Kept, and
  stated as a limit in the article.
- ChatGPT's 4 phone answers: all public lines (county referral service via a
  court guide, a court referral number, a bar pro bono intake line, a nonprofit
  immigration help line via a state legal aid office).
- Bare domains on Claude, Gemini and Perplexity were mostly directories, so no
  "website" count is reported; only links.

## Query

```sql
with p as (
  select id, client_id, row_number() over (partition by client_id order by id) rn
  from prompts where client_id between 28 and 47
), r as (
  select a.id, a.llm,
         case p.rn when 1 then 'pi' when 2 then 're' when 3 then 'pm' when 4 then 'imm' else 'city' end typ,
         replace(a.response_text, chr(92), '') t
  from ai_results a join p on p.id = a.prompt_id
  where a.client_id between 28 and 47 and a.status = 'ok'
    and a.llm in ('chatgpt','claude','gemini','google_ai','perplexity')
), f as (
  select *,
   t ~ '(\(\d{3}\)|\m\d{3})[ .-]\d{3}[ .-]\d{4}\M' phone,
   id <> 2489 and t ~* '\m\d{2,6} [A-Za-z0-9 .]{2,40} (st|street|ave|avenue|blvd|boulevard|road|rd|drive|dr|suite|ste|pkwy|parkway|fwy|freeway|hwy|highway|way|lane|ln)\M' addr,
   (select count(distinct m[1]) from regexp_matches(t, '\m(\d{2,6} [A-Za-z0-9 .]{2,40} (?:[Ss]t|[Ss]treet|[Aa]ve|[Aa]venue|[Bb]lvd|[Bb]oulevard|[Rr]oad|[Rr]d|[Dd]rive|[Dd]r|[Ss]uite|[Ss]te|[Pp]kwy|[Pp]arkway|[Ff]wy|[Hh]wy|[Ww]ay|[Ll]ane|[Ll]n))\M','g') m) naddr,
   t ~* 'https?://' url
  from r
)
select coalesce(llm,'ALL') llm, coalesce(typ,'ALL') typ, count(*) n,
 count(*) filter (where phone) phone, count(*) filter (where addr) addr,
 count(*) filter (where phone or addr) either,
 sum(naddr) filter (where addr) addr_strings,
 count(*) filter (where url) url
from f group by grouping sets ((),(llm),(typ),(llm,typ)) order by 1,2;
```

## Limits

- No address or number was checked for accuracy.
- Snippet text inside Google AI Mode answers is counted with the answer.
- Truncated storage can miss late mentions (Claude, Google AI Mode).
- One collection run in July 2026; not a statement about other days.
