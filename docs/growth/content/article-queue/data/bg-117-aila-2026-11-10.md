# BG-117 data record: AILA in immigration lawyer answers (2026-11-10)

Topic 18 `aila` from `topics.md`. Read only; SELECT and WITH only. No person's
name, firm name, address or phone number is recorded here: the repository is
public. Answers are referred to by `ai_results.id` only.

## Basis

- Clients 28 to 47 (20 US city research clients), `ai_results.status = 'ok'`,
  `checked_at < '2026-11-01'` (the July collection, 2026-07-24 and 2026-07-25).
  Without the date filter the November Los Angeles rows (client 28,
  `checked_at >= 2026-11-01`) enter and the immigration total reads 100.
- All prompt types: 585 ok answers (the corrected default basis). Immigration
  (rn = 4): 97 answers: chatgpt 19 (Los Angeles July rows deleted 2026-11-06),
  claude 20, gemini 20, google_ai 18, perplexity 20.
- Prompt type by `row_number() over (partition by client_id order by id)` on
  `prompts`: 4 is immigration.
- Text column: `response_text`, backslashes stripped. `citations` not used.
- Stored text caps: claude about 3,800 characters, chatgpt and google_ai
  10,000. Counts are lower bounds for those engines.

## Query 1: AILA, USCIS, EOIR by engine

```sql
with p as (
  select id, client_id, row_number() over (partition by client_id order by id) rn
  from prompts where client_id between 28 and 47
), r as (
  select a.id, a.llm, a.client_id, p.rn, a.checked_at, replace(a.response_text, chr(92), '') t
  from ai_results a join p on p.id = a.prompt_id
  where a.client_id between 28 and 47 and a.status = 'ok' and a.checked_at < '2026-11-01'
)
select coalesce(llm,'ALL') llm, count(*) n,
 sum((t ~* '\maila\M' or t ~* 'american immigration lawyers association')::int) aila,
 sum((t ~* '\muscis\M')::int) uscis,
 sum((t ~* '\meoir\M')::int) eoir,
 (select count(*) from r r2 where r2.rn<>4) other_n,
 (select count(*) from r r2 where r2.rn<>4
   and (r2.t ~* '\maila\M' or r2.t ~* 'american immigration lawyers association')) other_aila
from r where rn = 4 group by rollup(llm) order by llm;
```

## Query 2: Perplexity context and other credentials (immigration only)

```sql
with p as (
  select id, client_id, row_number() over (partition by client_id order by id) rn
  from prompts where client_id between 28 and 47
), r as (
  select a.id, a.llm, replace(a.response_text, chr(92), '') t
  from ai_results a join p on p.id = a.prompt_id
  where a.client_id between 28 and 47 and a.status = 'ok'
    and a.checked_at < '2026-11-01' and p.rn = 4
)
select llm, count(*) n,
 sum((t ~* 'I (don.t|do not) have (any )?(live |current |real-time )?search results|can.t (reliably|responsibly)')::int) no_results,
 sum((t ~* '(board.certified|certified specialist)')::int) board_cert,
 sum((t ~* '\m(state bar|bar association)\M')::int) bar,
 round(avg(length(t))) avg_len
from r group by llm order by llm;
```
