# Visual briefs

Format per `SKILL.md` 5.2, numbered to the post each serves. GBP shows a square
crop in most surfaces, so all four are 1:1.

**Two GBP-specific export constraints, both real and both easy to miss:**

1. **Minimum file size is 10 KB.** A mostly near-black 720x720 card with one line
   of text compresses well below that and GBP rejects it outright. Check byte
   size after export; pad with film grain or a dither pass if it lands short.
2. **Minimum dimension 250px, target 720x720.** Anything with text under roughly
   40px on a 720 canvas is unreadable at the size GBP actually renders it.

## Posting notes

- **This is a manual channel. Post it by hand.** Google Business Profile API post
  access needs a narrowly granted quota approval, and Product Posts cannot be
  created through the API at all. Do not build automation around these four.
- **GBP truncates well before the character limit.** The first sentence has to
  carry the offer on its own, because most readers never expand the post. All
  four are written with a self-contained opening line. Verify the exact fold
  against `docs/growth/channel-specs-2026-07-29.md` before scheduling.
- **Space these out.** Four GBP updates in a week on one profile reads as spam
  and GBP surfaces only the most recent one prominently anyway. One per week,
  in the order 4.2, 4.1, 4.3, 4.4, leading with the status-threat post because it
  is the only one that works on a reader who has never heard of the category.
- **EUR 449 and EUR 99 are the only prices in this package outside the earlier
  Grok folder.** If either moves, 4.1 and 4.3 are the only assets needing a
  rewrite, and neither image needs re-rendering.
- **Hold all four until the send gate clears.** GBP posts are indexed by Google,
  so a claim made here is harder to walk back than a social post.
